# Copy bank

Writer's weekday copy bank (`weekday-bank-v1.md`) lives here. It is an optional
caption source for the weekday cadence runner. An item is used only when its
source chapter is the chapter the picker allowed for that novel; otherwise the
runner falls back to generated copy.

Hashtags for Facebook and Instagram come from the repo's
`promo_copy.social_profile` hashtag lists (not from this bank, and not added to X).
