(A) SHARED ART-DIRECTION STYLE BRIEF  (apply to EVERY image)
====================================================================
STYLE: Traditional Korean MANHWA / webtoon (vertical scroll format).
NOT the purple-haze AI-painterly look. Think clean ink linework, flat color
blocks, screentone shading, limited palette, expressive faces.

VISUAL RULES:
- Linework: consistent black ink outlines, varying line weight (thick for
  foreground, thin for background). Hand-drawn feel, NOT airbrushed.
- Shading: screentones / hatch / flat gray fills. Minimal soft-gradient "AI glow."
- Palette (Studio brand + cultivation aura), KEEP IT MUTED, not neon-purple:
    Navy / near-black:  #07111F  (backgrounds, outlines, night)
    Electric blue:      #38C7FF  (the SYSTEM panel, UI text, Qi glints)
    Soft gray:          #D8DEE8  (highlights, screentone base)
    Skin / warm:        muted desaturated tones, NOT plastic-smooth
    Cultivation aura:   desaturated indigo/violet, used SPARINGLY (not dominant)
- The SYSTEM panel is PALE BLUE (#38C7FF on near-black), sharp rectangular
  UI with monospaced text. NEVER purple, NEVER a "sky eye."
- Composition: vertical webtoon panels, 3:4 or 9:16 friendly, negative space,
  Korean webtoon framing (close-ups for emotion, wide for environment).
- Characters: Kai = 19yo, dark messy hair, thin, tired, dark circles, cheap
  dark t-shirt, small rundown apartment. Express fatigue, then shock, then awe.
- Text in panels: hand-lettered caption boxes (black box, white text) for
  narration; the SYSTEM lines appear AS UI text inside the blue panel.
- NO forbidden elements (see section C). If the model tries a purple sky eye,
  hooded judges, or "Trial One," REGENERATE.
