`test_opencode_activation_cannot_run_kilo`. Both attempt two simultaneous
bindings and fail at the sealed `MAX_SIMULTANEOUS_REAL_BINDINGS=1` boundary.

diff from governing commit `d8bc304`, and none imports the EA-4E.47 module.

does not alter them or weaken the binding limit.

`test_multi_connection_claim_allows_exactly_one`: both concurrent claims denied
instead of exactly one allowing. That test had passed in the earlier 176-test
store run, passed immediately in isolation, and the full 284-test bounded gate
then passed without code changes. EA-4E.47 does not call `claim()` or alter the
store implementation. The event is classified as an existing concurrency-test
transient, not an EA-4E.47 regression.
