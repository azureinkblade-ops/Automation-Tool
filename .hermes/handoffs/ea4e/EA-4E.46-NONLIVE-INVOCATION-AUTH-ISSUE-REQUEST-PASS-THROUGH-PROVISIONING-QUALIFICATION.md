receiver, complete execution-authority artifact, binding handle, transport and
model IDs, runtime scope, operation, TTL, attempt number, nonce, and delegation
class. No authority-critical field has a constructor default.

The result is `PROVISIONED` or `DENY`. A provisioned result contains the exact
existing `ProductionInvocationAuthorizationIssueRequest` plus evidence fields
for the validated authority ID, binding ID, enablement ID, receiver, transport,
model, runtime scope, operation, and nonce.
