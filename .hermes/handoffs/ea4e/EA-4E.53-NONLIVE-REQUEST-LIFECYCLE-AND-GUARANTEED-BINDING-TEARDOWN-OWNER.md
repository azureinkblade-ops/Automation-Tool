The explicit `ProductionAppBindingProvisioner` remains outside the owner.

action. If no binding exists for the request's explicit receiver, the owner
fails closed before invoking the governed action.

## Responsibilities and Control Flow

```text
receive explicit governed request context
-> resolve the already-created binding for explicit receiver_id
-> fail closed if no binding was acquired
-> invoke existing qualified ProductionAppHostAction once
-> observe returned denial/success or caught exception
-> finally: teardown(the exact acquired binding) once
-> surface cleanup failure; otherwise return the governed result
```
