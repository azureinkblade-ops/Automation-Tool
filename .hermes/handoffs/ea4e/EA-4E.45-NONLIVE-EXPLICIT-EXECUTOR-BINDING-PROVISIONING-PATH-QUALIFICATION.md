## Blocking Evidence

The sealed controller evaluates `registry.bound_count` as `current_binding_count`.
`MAX_SIMULTANEOUS_REAL_BINDINGS=1`.

EA-4E.45 required:

- pre-registered executor in `ExecutorRegistry` or DENY
- wrap existing controller, no parallel binder
- no real-executor construction
- no auto-unbind
- no raising the sealed binding limit

Observed: placing a fake executor in the registry before `bind()` makes `bound_count=1`, so the first explicit bind returns `BINDING_LIMIT_EXCEEDED`.

Workarounds rejected:

- construct via `_resolve_executor_factory` (real executor construction)
- unregister then bind (auto-unbind)
- raise max simultaneous bindings (contract change)
- empty registry plus injected factory only (violates pre-registered DENY rule)

```text
BLOCKING_COMPONENT=ProductionExecutorBindingController.bind / ExecutorRegistry.bound_count
```
