Intent is written before ProductionExecutionBoundary.execute. PROCESS_STARTED / MODEL_INVOCATION_ENTERED are recorded only when ProductionExecutionResult.process_started / model_invoked are True (plus observed process_id and process_token for PROCESS_STARTED). executor_called is not process start. The default fake boundary leaves those flags False, so intents stay unresolved. A failed post-boundary write also leaves durable intent unresolved. EA-4E.58R2 HOLDS the original executor_called inference. EA-4E.58R3 removed it.
